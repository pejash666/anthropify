# v0.2.0-alpha — Key Revocation Checklist

This checklist is intended to be executed **after** the v0.2.0-alpha tag is
pushed to a public GitHub repository. Even though `.env.e2e` has never been
committed (verified via `git log --all --full-history -- .env.e2e` and full
history secret scan during the step-6 hygiene pass), the keys it contains
have been used from this workstation against live providers during e2e
development. Rotating them is cheap insurance before going public.

Mark each item complete only after the **new key works in `.env.e2e`** and
the old key has been confirmed revoked in the provider console.

## Post-rotation verification

After all six rotations:

```bash
./scripts/test-e2e.sh -v 2>&1 | tee /tmp/e2e-postrotate.log
grep -c '^--- PASS' /tmp/e2e-postrotate.log   # expect 32
grep -c '^--- FAIL' /tmp/e2e-postrotate.log   # expect 0
```

Then delete `/tmp/e2e-postrotate.log`.
